## Зорилго

Энэ репозитори нь агуулахын бүртгэлийн системийг сурган хөгжүүлэх **38 долоо хоногийн төлөвлөгөө** боловсруулах ажлын талбар юм.

Төлөвлөгөөний ерөнхий чиглэл:

- Агуулахын орлого, зарлага, үлдэгдлийн бүртгэлийн бизнес ойлголтоос эхлэх
- Шаардлага, өгөгдлийн загвар, API, UI, тестийг шат дараалуулан хамрах
- JavaScript (Node.js) болон Python (FastAPI) хоёр замаар хэрэгжүүлж харьцуулах
- Git, GitHub дээр ажлаа нотолгоотойгоор хөтлөх
